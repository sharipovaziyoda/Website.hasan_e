# Website.hasan_e
Created with CodeSandbox 
This project is designed as a personal portfolio or landing page, with cards displaying products. Selected products are added to the cart, and the user has the ability to increase or decrease their quantity.

## 🛠 Technologies
- HTML
- CSS
- JavaScript

- ## ✨ Tasks
- Show the user information about products and cart
- Create cards for products
- Cart system (save selected products, increase or decrease their number)
- User interface (UI) beautiful and user-friendly design

- ## 👩‍💻 Created Environment
- CodeSandbox
- Then uploaded to GitHub
